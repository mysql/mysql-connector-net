Connector/NET 26.7 Release Notes
------------------------------------
Welcome to the release notes for Connector/NET 26.7

What's new in 26.7
--------------------

Connector/NET updated third-party dependencies.
Connector/NET fixed an issue where LINQ .Contains predicates with collection parameters could fail in EF Core because the collection elements were not mapped correctly.
Connector/NET fixed an issue with parameterized query handling.
Connector/NET fixed an issue with restriction value handling in GetSchema metadata queries.
Connector/NET fixed an issue with TLS certificate validation.
