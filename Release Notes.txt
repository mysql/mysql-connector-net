Connector/NET 26.10 Release Notes
------------------------------------
Welcome to the release notes for Connector/NET 26.10

What's new in 26.10
--------------------

Connector/NET added support for .NET 11 and EF Core 11 preview versions.
Connector/NET fixed validation of the AllowLoadLocalInfileInPath connection option.
Connector/NET fixed a NullReferenceException when using a GUID array in an Entity Framework Core LINQ Contains query.
Connector/NET fixed authentication handling when the active connection transport differs from the configured connection settings.
